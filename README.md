# TGT Analytics — Enterprise & SMB AI Platform

> **Slogan:** "Real-World Business, AI-Powered Solutions"

TGT Analytics bridges enterprise-grade software engineering, autonomous business agents (consolidating the **SyncBiz Agent Engine** from `syncbizagent.com`), and predictive AI Business Intelligence.

---

## 🎨 Design System — Factory Style Reference

- **Canvas & Base:** `#101010` (Obsidian Canvas)
- **Signature Figure/Ground Card:** `#eeeeee` (Bone Card) floating on obsidian canvas
- **Raised Dark Surfaces:** `#1d1a18` (Carbon Lift)
- **High-Emphasis Action:** `#fafafa` (Chalk)
- **Functional Accents:** `#ee6018` (Signal Orange for live status, sparklines) and `#a0ca92` (Metric Green for positive trends)
- **Typography:** Geist & Geist Mono with tight negative letter-spacing and flat weight 400

---

## 🚀 Core Pillars

1. **Custom Software & Systems Development**
   - High-throughput backend systems, distributed microservices, clean/hexagonal architectures, legacy ERP/CRM bridges.
2. **Autonomous Business Agents for SMBs (Powered by SyncBiz)**
   - 24/7 autonomous operations: CRM sync, lead routing, automated invoice reconciliation, multi-channel dispatch (Email, WhatsApp, Slack, Web).
3. **AI-Powered Business Intelligence**
   - Automated data marts (Snowflake & PostgreSQL), real-time revenue leak interception, natural-language executive queries, predictive inventory & churn forecasting.

---

## 🛠️ Interactive Modules Included

- **macOS War Room Dashboard**: Live telemetry, sparklines in `#ee6018` and `#a0ca92`, and simulated real-time autonomous event stream.
- **Trust Logo Strip**: Negative-space monochrome tech stack wordmarks in `#8a8380`.
- **SyncBiz Signature Bone Card**: Dynamic sector switcher (Agencies, Operations & SMBs, Growth & Marketing, Wealth AI).
- **Interactive Predictive BI Console**: Revenue velocity vectors, inventory depletion mitigation, and customer retention telemetry.
- **Interactive ROI & Hours-Saved Simulator**: Dynamic sliders for team size, manual hours/week, and blended hourly rates with instant financial metrics.
- **3-Stage Architecture Pipeline**: Multi-source ingestion $\rightarrow$ SyncBiz Orchestration Kernel $\rightarrow$ Autonomous execution & live data marts.
- **Technical Consultation & Workflow Audit Form**: Interactive form with live validation and state transitions.

## 💻 Running the Platform Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

```
